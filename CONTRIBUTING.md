# Contributing

Bug reports and pull requests are welcome.

## Building

```sh
swift build                 # compile
scripts/build_app.sh        # create build/KeepAlive.app
open build/KeepAlive.app
```

Xcode 15 or later is required. You can also open `Package.swift` in Xcode, but the
menu bar app needs a real bundle for notifications and the login item, so test
those with `scripts/build_app.sh`.

## Guidelines

- Keep the interface native: system fonts, system colors, standard controls. Follow
  the [Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/).
- Every user-facing string goes through `Resources/Localizable.xcstrings`. Please add
  the German translation too, or leave it marked as untranslated.
- Keep background work cheap. A scheduled check must not start `xcodebuild` or
  `devicectl` unless an app is actually due.
- The app icon is generated by `scripts/render_icon.swift` as an Icon Composer document.
  Change the script, or open `Resources/AppIcon.icon` in Icon Composer.

## Bug reports

Please include your macOS and Xcode versions and the relevant part of
`~/Library/Logs/KeepAlive/`. Remove anything personal, such as your team ID.
